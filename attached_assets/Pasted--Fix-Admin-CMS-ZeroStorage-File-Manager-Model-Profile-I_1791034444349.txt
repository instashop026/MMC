# PART 16 — VIDEO FILENAME HASHTAGS → STYLES

Video filenames may contain hashtags.

Example:

```text
video_01 #cosplay #blonde #outdoor.mp4
```

The importer should detect hashtag tokens in the filename.

For example:

```text
#cosplay
#blonde
#outdoor
```

becomes styles:

```text
Cosplay
Blonde
Outdoor
```

These styles apply only to that specific video post.

IMPORTANT:

Do not create a giant complicated hashtag parser.

Use a simple robust pattern that detects `#word` tokens.

Normalize the style name according to the existing style normalization system.

If the style already exists:

```text
use existing style
```

If it does not exist:

```text
create the style
```

Then attach it to that specific post.

The hashtag itself does not need to remain in the caption unless that is already part of the existing product behavior.

The important requirement is:

```text
filename hashtag
        ↓
style
        ↓
post_style
```
